# firmware-can

Robotell USB-CAN 어댑터의 원래 펌웨어입니다. PC와 CAN 버스 사이에서 CAN 프레임을 양방향으로 중계합니다.

## 동작

- **CAN → PC**: 수신한 CAN 프레임을 `CAN_msg` 구조체 그대로 Robotell 패킷에 담아 USART2로 보냅니다.
- **PC → CAN**: PC가 보낸 패킷을 풀어 CAN 버스로 송신합니다.
- **설정**: 채널 값이 `0xff`인 패킷은 CAN으로 내보내지 않고 설정 명령으로 처리합니다. 설정값은 내부 플래시(`0x08008000`)에 저장되어 전원을 껐다 켜도 유지됩니다.

## PC 쪽 패킷 형식

```
AA AA | 데이터 … | 체크섬 | 55 55
```

- 데이터 안에 `AA`, `55`, `A5`가 나오면 앞에 `A5`를 붙여 구분합니다.
- 체크섬은 데이터 바이트의 합(하위 8비트)입니다.
- 데이터는 16바이트 `CAN_msg`입니다: ID(4), 데이터(8), 길이(1), 채널(1), 형식(1), 종류(1).

## 설정 명령

채널 `0xff`, 확장 ID로 보냅니다. 원격 프레임이면 현재 값을 돌려주고, 데이터 프레임이면 값을 바꿉니다.

| ID | 내용 |
|---|---|
| `0x01fffed0` | CAN 보레이트 |
| `0x01fffee0` + n | n번 필터(ID, 마스크, 사용 여부, 표준/확장) |
| `0x01fffeb0` | ABOM (bus-off 자동 복구) |
| `0x01fffea0` | ART (자동 재전송) |
| `0x01fffec0` | CAN 재시작 |
| `0x01fffeff` | 공장 초기화 |
| `0x01fffe90` | PC 쪽 USART 보레이트 |
| `0x01ffffe0` | 펌웨어 버전 조회 |
| `0x01fffff0`, `0x01fffff1` | CPU 고유 ID 조회 |

기본값은 CAN 500kbps, PC 쪽 115200bps입니다.
